# Rain Drop Valley View Cottage Stay

A modern, responsive website developed for **Rain Drop Valley View Cottage Stay**, located in Madikeri, Coorg, Karnataka. The website showcases the property's accommodation, amenities, experiences, nearby attractions, and booking enquiry options.

## Overview

Rain Drop Valley View Cottage Stay is a live hospitality website designed to provide visitors with a seamless browsing experience across desktop, tablet, and mobile devices.

The website features a modern interface, smooth animations, interactive elements, and an integrated enquiry system.

## Features

- Fully responsive website
- Modern and interactive user interface
- GSAP animations and scroll effects
- Smooth scrolling with Lenis
- Accommodation and room information
- Amenities and activities showcase
- Interactive image gallery
- Nearby attractions section
- FAQ accordion
- Contact and booking enquiry form
- Client-side form validation
- Google Apps Script integration
- Google Sheets enquiry management
- Automated email notifications
- SEO-friendly HTML structure

## Technologies Used

## Form Integration

The website includes a booking enquiry form integrated with Google Apps Script and Google Sheets.

The form supports field validation, guest count verification, date validation, enquiry submission, and administrator email notifications.

## Responsive Design

The website is optimised for desktop, tablet, and mobile screen sizes, with responsive layouts, typography, navigation, and interactive components.
